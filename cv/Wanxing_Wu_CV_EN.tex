\section{Research Experience}
\entry{\unilogo{sustech.png}\enskip SUSTech-NLP}{Shenzhen, China}
\textit{Research Assistant}\hfill\textit{Jan 2025 -- Present}\\
Research advisor: \href{https://ghchen.me/}{Guanhua Chen}.
\researchitem{Agent exploration and experience learning}{\trl}{To adapt to unfamiliar environments, agents first need to explore and gather information for their tasks. Studied \textbf{how to acquire useful exploration experience efficiently}, using two controlled experiments to examine environmental clues, candidate-space size, and inspection count. Proposed \textbf{Scope-then-Cover}: a strong actor selects exploration scopes based on the task; weak scouts inspect candidates in parallel and return observations. Applied the method to household, shopping, and coding tasks to help agents gather information for task decisions, then reused exploration trajectories for online learning and an experience memory to improve performance on later tasks.}
\researchitem{Multi-view on-policy self-distillation}{\badge{tagrl}{post-training}}{Studied how to \textbf{consolidate complementary reasoning capabilities elicited under different conditions into a single policy}. Using cross-lingual reasoning as a testbed, proposed \textbf{CMOPD, Cross-lingual Multi-view On-Policy Self-Distillation}: fused token-level supervision from a frozen model under different language conditions to guide student-generated reasoning trajectories. After training, the model reasons directly in the target language without multilingual generation or answer aggregation. Compared reasoning performance at three model scales across four low-resource languages, examining what different language views contribute and how to combine their supervision effectively.}
\researchitem{Edge--cloud model routing evaluation}{\troute}{Edge--cloud collaboration handles routine requests with a local small model and calls a cloud LLM when needed. With limited cloud spending, which requests should receive priority? Studied \textbf{how to evaluate the allocation of cloud resources} through \textbf{RouterXBench}, assessing whether routers identify requests the small model struggles with, alongside the resulting answer quality and cloud cost. Compared \textbf{prioritizing difficult requests versus helping more requests}, and how budget and quality requirements affect router selection. Built six tests spanning instruction following, knowledge, and mathematics, and provided \textbf{MeanProbe}, a lightweight reference router.}
